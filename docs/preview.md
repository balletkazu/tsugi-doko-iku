# 試遊・検証・デプロイ

## スマートフォンで試せる操作

1. ホームで九十九島の写真とクレジットを確認する。「みんなの旅」「写真」「旅の日記」「旅の栞」を切り替える。
2. サンプル投稿を開いて反応・保存を試す。「フォロー中」で編集部のサンプルをフォローし、再読み込みして同じ端末に残ることを確認する。
3. 「旅を発見」で旅先をテーマ・地名で絞る。写真のクレジットを確認し、保存した旅先と投稿を切り替える。
4. 「行き方」で出発地・目的地・徒歩の上限を選び、入力した条件を確認する。アプリ内の経路検索は準備中。「寄り道を探す」で掲載地点を探せる。
5. 「私の旅」で栞を作り、写真を取り込む。保存、修正、テキスト共有、印刷・PDFを試す。
6. 日記に場所、気持ち、本文、写真を入力して保存する。プレビューの公開範囲は自分だけ。
7. 都道府県のスタンプを押す。旅人タイプを選び、発見で好みのテーマが先に表示されることを確認する。

## 開発時のテスト

`npm test` は検索、外部地図 URL、寄り道距離、コレクション識別子、プライバシーに関わるエスケープ、オフライン対象のビルドを検証する。ブラウザーでは画面幅320／390／768pxで一覧、フォーム、ナビゲーション、画像読み込みを確認し、スマートフォン実機ではネイティブ共有、写真選択とオフライン復帰を追加確認する。

## Vercel のブランチプレビュー

専用ブランチ `codex/travel-app-preview` を使う。Vercel 設定は GitHub の対象リポジトリをルートとして `npm run build` を実行し、`dist/` を公開する。API キー、環境変数、データベース設定は不要。Git 連携による Preview で該当ブランチのコミットと HTTPS URL を照合する。`main` のマージと Production デプロイはオーナーの確認後に扱う。
