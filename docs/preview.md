# 試遊・検証・デプロイ

## スマートフォンで試せる操作

1. 新しいタブで起動し、全画面写真をタップで閉じる。「ここは、どこ？」から写真の撮影場所と出典を見る。
2. ホームでサンプル投稿を切り替え、`#秋田` や `#水辺` で検索する。投稿の反応、保存、編集部のサンプルのフォローは端末に保存される。
3. 「投稿を書く」で写真を選び、掲載順、表紙、説明、撮影場所を設定して下書きを保存する。全画面でスワイプ・拡大を試す。
4. 「私の旅」で地球儀やカメラをタップする。一覧表示も選べる。スタンプを押し、メダルを受け取る。「音と動き」で設定を変更できる。
5. 部屋の鏡から旅人タイプを診断する。保存先を使う許可を選べる。ジャーナリングと写真の下書きは非公開。
6. 「行き方」から「富山市で検索する」を開き、徒歩30分・1時間・2時間で候補を比較する。[検索例](toyama-pilot.md)

## 開発時のテスト

`npm test` は検索、外部地図 URL、寄り道距離、コレクション識別子、プライバシーに関わるエスケープ、オフライン対象のビルドを検証する。ブラウザーでは画面幅320／390／768pxで一覧、フォーム、ナビゲーション、画像読み込みを確認し、スマートフォン実機ではネイティブ共有、写真選択とオフライン復帰を追加確認する。

## Vercel のブランチプレビュー

専用ブランチ `codex/travel-app-preview` を使う。Vercel 設定は GitHub の対象リポジトリをルートとして `npm run build` を実行し、`dist/` を公開する。API キー、環境変数、データベース設定は不要。Git 連携による Preview で該当ブランチのコミットと HTTPS URL を照合する。`main` のマージと Production デプロイはオーナーの確認後に扱う。
