# 試遊・検証・デプロイ

## スマートフォンで試せる操作

1. ホームで風景を見て「旅先を見つける」を開く。「海・島」などのテーマや入力した地名で絞る。
2. 旅先カードのハートを押し、「保存した場所」を開く。ページを再読み込みしても同じブラウザーで確認できる。
3. 旅先の詳細から「行き方を調べる」を開く。出発地、徒歩の目安、優先条件を選び、Google マップへのリンクを確認する。「この周辺で寄り道」で掲載地点を探す。
4. 「私の旅」で栞を作り、タイトル・旅程・写真を入力する。保存、修正、テキスト共有、印刷・PDFを試す。
5. 日記に場所、気持ち、本文、写真を入力して保存する。公開範囲はこの版では自分だけ。
6. 都道府県のスタンプを押す。旅人タイプの好みを保存し、発見の表示順を確認する。
7. ホームのサンプル読みものに反応を付ける。反応は端末に記録される。

## 開発時のテスト

`npm test` は検索、外部地図 URL、寄り道距離、コレクション識別子、プライバシーに関わるエスケープ、オフライン対象のビルドを検証する。ブラウザーでは画面幅320／390／768pxで一覧、フォーム、ナビゲーション、画像読み込みを確認し、スマートフォン実機ではネイティブ共有、写真選択とオフライン復帰を追加確認する。

## Vercel のブランチプレビュー

専用ブランチ `codex/travel-app-preview` を使う。Vercel 設定は GitHub の対象リポジトリをルートとして `npm run build` を実行し、`dist/` を公開する。API キー、環境変数、データベース設定は不要。Git 連携による Preview で該当ブランチのコミットと HTTPS URL を照合する。`main` のマージと Production デプロイはオーナーの確認後に扱う。
