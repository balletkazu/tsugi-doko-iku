# 富山市の経路検索の試作

「行き方」から「富山市で検索する」を開く。富山市のまいどはやバス（東・西ルート）について、バス1便と前後の徒歩、または徒歩のみの経路を出発時刻順のダイヤに照らして検索する。待ち時間を含めて到着の早い候補を表示し、徒歩の合計は待ち時間を除いて秒単位で比較する。徒歩30分・1時間・2時間の上限を越えた候補は表示しない。乗車不可・降車不可の停留所は候補から除く。2便以上の乗換、別事業者、リアルタイムの遅延、通行止めは対象外。

## 試せる例

収録期間内の 2026年11月25日、日本時間10:00、出発地「富山駅前」で検証した。

- 「磯部町四丁目」へは30分でバスを含む候補が表示され、1時間に広げると約31分の徒歩のみが加わる。
- 「富山市ファミリーパーク周辺」は1時間以内の候補なし。2時間なら徒歩約98分とバスを含む候補が表示される。まいどはやバスの収録範囲での試算で、ファミリーパーク行きのバスが運行しているという意味ではない。

## データとライセンス

- 日時・停留所・路線・運賃。富山市「まいどはやバスGTFS-JP」、2026/04/01改正、収録期間2026-04-01〜2027-03-31。2026-11-25に取得。配布ZIPの SHA-256 `5d273f956ac110249909e9c01dc1cb51ac63e8577f76f64db7fc11e036749b82`。必要な列を抽出して [時刻表スナップショット](../public/data/toyama-schedule.js) に収録した。[富山市の原本（CC0）](https://opdt.city.toyama.lg.jp/dataset/toyamacity-bus-gtfs-jp/resource/43903d9f-1d9c-42f0-bd01-8a5fc1cb828c)
- 徒歩。© OpenStreetMap contributors（ODbL）。停留所と選択できる地点周辺の歩行秒数を FOSSGIS の OSRM 歩行プロファイルで2026-11-25に一括算出し、秒を切り上げて [徒歩行列](../public/data/toyama-walking.js) として ODbL で配布する。停留所は収録座標を使用。富山県美術館・ファミリーパークは周辺の固定地点で、施設の入口や歩行路の実測ではない。道路へのスナップ結果は最大約51m。アプリ利用時に経路データ提供元へのリクエストや現在地の送信は行わない。[FOSSGIS のサービス説明](https://routing.openstreetmap.de/about.html) · [OpenStreetMap の著作権・ODbL](https://www.openstreetmap.org/copyright) · [地図の修正](https://www.openstreetmap.org/fixthemap)

アプリは収録期間外の検索結果を出さない。今後はフィード更新を確認し、停止・変更を表示する。加入、契約、キーはこの試作に不要。地域や事業者の拡張、実運行への対応は [比較と開発計画](transit-evaluation.md) で扱う。
