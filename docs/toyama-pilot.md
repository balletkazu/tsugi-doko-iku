# 富山市の路面電車・バス・徒歩検索

「行き方」から「富山市で検索する」を開く。富山地方鉄道の市内電車と、まいどはやバス東・西ルートの時刻表を使い、停留所や収録地点の間を徒歩でつなぐ。乗車3回（乗り換え2回）まで、出発から6時間以内の到着候補を表示する。各候補には経路、乗り降りする停留所、出発・到着時刻、徒歩時間が出る。

徒歩30分・1時間・2時間は、乗車前、乗り換え、降車後を足した上限。待ち時間は歩行時間に含めない。未収録の徒歩経路は候補に使わない。試作では乗り換えごとに徒歩時間とは別に2分を確保する。運休、遅延、工事、通行止め、対象外の事業者、IC運賃や乗り継ぎ割引は未反映。徒歩時間は歩行ネットワーク上の推定で、天候、勾配、横断待ち、個人差は反映しない。

## スマートフォンで試せる例

日付を2026年11月25日、出発を日本時間10:00にして確認できる。

- 「護国神社・富山まちなか病院前」→「岩瀬浜」で「路面電車とバスの両方を使う」を選ぶ。東ルートで宝町まで乗車し、富山駅まで約6分歩き、10:30発の市内電車に乗り換えて岩瀬浜に10:54到着する候補が出る。
- 「富山駅前（バス）」→「磯部町四丁目」で、徒歩30分では公共交通を含む候補、1時間では徒歩のみ約31分の候補も表示される。両方の交通手段で絞るチェックを外す。
- 「富山駅前（バス）」→「富山市ファミリーパーク周辺」は1時間以内の候補なし、2時間では候補が出る。収録範囲での試算なので、別事業者が提供するファミリーパーク方面のバスは検索に含まれない。

両方の時刻表が揃う2026-04-01〜2027-03-13に限定して検索する。時刻表ZIPから取得した SHA-256、データバージョン、期間は[同梱データ](../public/data/toyama-schedule.js)に記録した。市内電車の配布ZIPでは `route_type=3` だが、公開元の分類と路線名に基づき、このフィードだけを路面電車に正規化している。他フィードへは適用しない。電車のZIPに運賃表が収録されていないため、電車を含む候補に合計運賃を表示しない。

アプリは収録データを端末内で検索する。時刻表や徒歩サービスへ検索条件を送信することはなく、APIキー・会員登録は不要。データの取得、更新、他地域に広げる設計は[オープンデータ運用](open-transit.md)を参照。
