# 旅人の身支度と、家を育てる旅

## プレビューで遊ぶ

- 身支度で髪・肌、顔、服、小物、体型、しぐさを選べる。旅人をタップすると喜び、回転ボタンで後ろ姿も確認できる。顔の各部の位置、大きさ、角度、両目・眉・耳の間隔を調整できる。服の色、柄、布の質感と重ね着を切り替えられる。おまかせ、取り消しとやり直し、6つのコーデの保存を用意した。すべての基本パーツと調整は無料。
- 自宅では床や家具そのものをタップする。旅人は家具を避けて歩き、ベッドで眠り、本棚では本を読み、お茶のテーブルでは腰を落ち着ける。家具一覧からの操作も可能。画面をドラッグして見渡せる。2本指と拡大・縮小ボタンを使用できる。
- 模様替えで棚の家具をドラッグして置くか、家具を選んで床をタップする。配置前に半透明で表示し、重なる場合は赤く示して確定しない。家具を動かす、回す、片づける、写真を掛ける操作がある。キーボードでは矢印とEnterで操作できる。「広げる」で独立した部屋と奥の庭を追加できる。室内は壁紙・床・窓・照明、庭は屋根・外壁・植地の色調を切り替えられる。
- 街の占いの館では、灯（あかり）と10問または32問の会話をする。絵札を1問ずつ選び、二つの旅人タイプの結果カードを受け取る。旅の記録の利用は本人が選べる。日記の本文、写真、位置履歴は使用しない。自己発見の遊びとして提供する。
- 都道府県と具体的な場所および活動を本人が記録すると、合う記念品が図鑑と家具棚に届く。例えば富山県、立山・室堂、登山の組で雷鳥の彫刻を得られる。図鑑には8件と各出典がある。登山、美食、遊び、リゾート、鉄道、写真、温泉、アートなど10種の短い記憶を持ち帰れる。信仰の由来は、任意で図鑑を開いた人だけが読める。地域の提案は下書きを保存し、テキストに書き出せる。

旧版のアバター、訪問スタンプ、旅コイン、おとも旅、旅の栞、SNSの試遊機能、地図、GPS、写真を継続利用できる。旧版で飾った物と写真は新しい家に読み替える。家具や証は期限なしで残る。富山の実ダイヤを用いる乗換案内は街の駅と通常メニューから開ける。

## 作画と実装の方針

承認済みの原画を基準に、形状を重ねる旧描画から雨の布地、革の靴、髪の束、刺しゅうまで描いた透過ラスターへ切り替えた。基準としたのは2頭身前後のバランス、細い茶色の輪郭、頬の暖色、布と木のつやを抑えた質感、家と人物の縮尺。スプライトシートから各コマを切り出し、輪郭のマゼンタ残りを抑えて透過WebPにした。新素材は `python scripts/pack-atelier.py heads 入力.png 出力.webp` のように生成できる。1セル128pxで、髪の向きごとに同じ順番と顎の位置を使う。資料の説明文字、ロゴ、UI画像はゲームの素材に流用していない。

`public/assets/atelier/` に方向、動作、正面・横・後ろの髪、服、アクセサリー、家具、おみやげ・絵札を同梱する。空室、庭、占いの館も本プロジェクト用の新規画像生成。各種作品に付随する既存の公式グッズ、第三者のゲームキャラクターや公式ロゴは使用していない。撮影した風景写真の権利は既存の [写真台帳](photo-credits.md) に従う。地域の題材では、アプリ内図鑑から観光協会、社寺、県等の一次資料にリンクし、資料の画像や文章は転載しない。

キャラクター・カメラ・家具をCanvas 2Dにまとめ、フォーカスと操作部をHTMLで提供した。Canvasと配置データは分け、世界座標、家具の幅と高さ、描画の高さ、通行判定を別々に持つ。Canvasを採用したのは同時表示数が少なく追加のランタイムを載せずに済むため。マップや動体が大きく増えた段階ではPixiJSやPhaserで描画負荷、アセット管理、アクセシビリティの接続工数を比較する。

### 現時点の制約

- 正面の着せ替えが最も詳細。移動・背面などでは、対応する髪と色を適用する。複雑な睡眠・食事・登山などは描き下ろしモーションを使うので、顔や服のすべての組み合わせをまだ反映しない。すべての動作で忠実なパーツを増やす場合は、原画提供元から正面・背面・横・斜めの透過PNGと、髪・顔・上半身・脚・装備に分かれた原寸レイヤーを受け取れると、枠を合わせて差し替えられる。歩行は同じ足元、顔パーツは同じ目線と頭の中心が基準。長期目標の素材数は制作を続ける。
- 家はタイル単位で配置する。回転で占有範囲が変わる。家具画像の方向表現は一部に鏡映を用いる。建物外観は色調の変更。屋根や外壁を別形状の建築物へ自由に交換する機能は次の制作範囲。
- 地域提案のWeb版は端末内の下書きまで公開した。公開サーバーと編集部の審査画面の接続後、採用した提案に「ふるさとの語り部」を贈る。DB試験では下書きの非公開、本人による提出、編集側のみの採用、メダル重複防止を検証した。
- 実機の操作性と、長時間編集したときの楽しさは、Android/iPhoneでの観察が必要。ブラウザ試験では画面の表示と入力動作を確認する。
