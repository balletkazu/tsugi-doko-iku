# つぎ どこ行く？ 開発仕様書

対象は `balletkazu/tsugi-doko-iku`。CYCLE は独立したプロジェクトで、この開発の操作対象から外す。

## プロダクトの目的

旅を通して世界に触れ、好奇心を満たし、人とつながり、自分自身の人生を豊かにする。主役は世界とユーザー。アプリを開くこと自体を目的にせず、現実の世界を楽しむきっかけをつくる。共有では他者との比較や承認の獲得より、経験が誰かの役に立つことや、貢献に喜びを感じられることを重視する。多くの旅人が安心して利用できる商用サービスを長期目標とする。

## UX・デザイン

Windows の壁紙を思わせる、視界が開ける美しい自然風景をホームの中心に置く。洗練されたシンプルさ、直感的な操作、十分な余白を重視する。ロゴは丸みのある手書き風にし、ブランドの主張は控えめにする。アプリを開いた瞬間に旅に出たくなる風景と、すぐ目的の操作に進める実用性を両立する。スマートフォンを優先し、デスクトップにも対応する。無限スクロールを避け、読み終わりや区切りが分かる有限の表示を採用する。

## 機能

| 領域 | 目標と受け入れ条件 |
|---|---|
| ホーム | 美しい風景を入口に、旅先、他の旅人の写真・記録・体験に自然に触れられる。有限の特集を見て次に進める。 |
| 旅の発見 | 有名・無名を問わず、渓谷・滝・山・海・温泉・神社・文化・アートなどの旅先を探せる。旅人タイプからテーマを探しやすくする。 |
| ルート検索 | 公共交通機関と徒歩を柔軟に組み合わせる。徒歩30分・1時間・2時間などを選べる。最短以外にも風景や寄り道を楽しめる候補を扱い、車を使わない旅を支える。運行・料金・徒歩条件の適用有無を正しく表示する。 |
| 寄り道 | 旅の途中に、現在地付近や移動経路上の魅力的な場所を探せる。候補の近さ、経路との関係、交通情報の出典を表示する。 |
| 旅の栞 | 写真、旅程、地図、交通情報を組み合わせ、見返しやすい栞を作成・保存・共有できる。 |
| 日記 | 写真、文章、訪問場所、気持ちを数ステップで記録する。既定は自分だけ。限定公開と一般公開は意図的に選択でき、公開範囲を設定・変更できる。 |
| SNS | 写真・日記・栞・体験を共有し、「ありがとう」「行ってみたい」「参考になった」を送れる。ランキングやフォロワー数を競わせず、投稿が誰かの旅行の役に立ったことが分かる。ブロック・ミュート・通報・公開範囲の設定を揃える。 |
| コレクション | 47都道府県、国立公園、世界遺産、日本百名山、ユネスコ世界ジオパークの訪問をスタンプ帳と地図で確認できる。達成の表彰を用意し、国や地域単位で拡張できるデータ構造にする。 |
| 旅人タイプ | 冒険家、ネイチャーラバー、アーティスト、登山家などの好みを発見に使う。初期は任意の自己選択式にし、後から変更できる。 |
| 写真 | スマートフォンとデジタルカメラ由来のファイルを取り込める。美しく見返し、公開設定の上で共有できる。対応形式と容量を表示する。 |

## 利用料金の方針

基本無料で、一般的な広告を掲載しない。無料でも発見・計画・記録を十分に使えるようにする。月額500円程度の有料プランは将来の検討事項。高度な栞の作成など、明確な追加価値を検証する段階で設計を具体化する。有料契約や有料機能の有効化はオーナー承認を要する。

## 技術・運用の方針

- 既存の4試作版の成果を調査・保持し、必要に応じ構造を再設計する。PWA を起点に Android・iOS への発展を考慮する。
- 認証、データベース、画像保存、プライバシー、セキュリティ、位置情報、投稿の安全管理、アクセシビリティを設計・検証する。
- 外部 API の価格・上限・利用規約・代替手段を整理する。サービス登録、情報接続、有料契約など承認が必要な箇所はオーナーに確認する。
- 交通時刻、料金、施設情報の架空データは実データとして表示しない。サンプルと生成画像に表示を付け、実際に使える機能の範囲が分かる UI にする。
- 依存や人気競争を促す設計を避け、公開前にアクセス制御、悪用対策、通報処理、写真の位置情報除去を検証する。

## 開発の進め方

この仕様をリポジトリで管理する。既存コードを調査し、設計と計画を立て、専用ブランチで動く版を段階的に実装する。テスト、バグ修正、スマートフォンでの確認を進め、PR を作成し、Vercel のブランチプレビューを公開する。`main` へのマージはオーナーの確認後に行う。日常の実装判断、ファイル管理、検証、回復作業は自律的に進め、重要なデザイン変更、費用、サービス登録、認証に判断が必要な場合はオーナーに相談する。計画と実装済みの境界は [開発計画](architecture.md) で管理する。
