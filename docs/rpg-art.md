# 旅の手帖の作画帳

世界を一枚の見開き絵本として描く。プレイヤーは、古い駅舎と野の花の間を歩く小さな旅人。道具の意匠には、切手の目打ち、角を丸めた切符、方位磁針を使う。

背景は斜め上からの平行投影。陰は右下に一段、手前の輪郭は濃く、遠景は低コントラストにする。紙の粒子はごく少なく、金属光沢や強いぼかしは使わない。季節の気配は草木、水の色と小さな花で描く。現実の写真には画風を適用しない。

人物は原寸およそ16×24のドットで頭と胴の比がおおむね1対1。顔、髪、上着、靴などを同じ整数座標に重ね、顔立ちと肌の色は独立して選べる。輪郭は1ドットを基本にする。動作の違いは腕・脚・道具の位置で読み取れるようにする。画面の文字はドットにせず、タップは絵より大きな領域で受ける。

音は希望した場合のみ。動きの軽減設定に従い、動作を静止姿勢でも識別できるようにする。地理に基づく地図と創作の街並みはそれぞれ明示する。

## 今回の原画と完成素材

2026年11月25日の利用者提示・承認済みの「キャラクターデザイン案」と「制作イメージ」を、色、頭身、濃い茶の細い輪郭、まるい目、木と紙の質感の基準にした。原画を画面のスプライトに切り貼りせず、Canvasのレイヤーで輪郭、顔立ち、髪、服、道具を組み合わせる描画を制作した。動作で足の振り、姿勢、道具、まばたきや喜びの表情を変える。プレビューは体格の3段階ずつと顔・髪などの選択を即時反映する。

街と家の背景 `street.webp` と `inside.webp` は、この原画を参照してOpenAIの画像生成で本プロジェクトのために新規制作した。ゲーム中の移動経路・施設の判定は独立したHTMLとJavaScript。従来の四季風景と実写は引き続き表示する。スタンプはプロジェクト内でCanvas描画し、各所の公式ロゴを使わず、地形・建物のモチーフで表現する。

## 透過スプライト版

新しい承認済み原画と、それまでの承認資料に沿って、旅人の形と衣服、室内の木や布の質感を作画基準とした。ゲーム内の絵はプロジェクト用の画像生成をもとに、透過処理、セルの整形、基準点の合わせ込み、レイヤー合成を行った。原画そのものの表示や第三者素材の引用とは異なる。方向・動作、髪、服、小物、家具、絵札などの素材構成と今回の収録数は [透過スプライト版の試遊ガイド](atelier-preview.md) に記録した。
