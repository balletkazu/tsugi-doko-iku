# 旅の手帖の作画帳

世界を一枚の見開き絵本として描く。プレイヤーは、古い駅舎と野の花の間を歩く小さな旅人。道具の意匠には、切手の目打ち、角を丸めた切符、方位磁針を使う。

| 用途 | 色 |
| --- | --- |
| 紙・生成り | #f5ecd6 |
| インク・森の輪郭 | #344b43 |
| 水・遠い山 | #86b2ad |
| 草原・木の葉 | #9cab79 |
| 日向・窓の灯 | #e9c77f |
| 瓦・旅のスカーフ | #bf7253 |
| 木・革 | #966c51 |
| 夜・影 | #56686d |

背景は斜め上からの平行投影。陰は右下に一段、手前の輪郭は濃く、遠景は低コントラストにする。紙の粒子はごく少なく、金属光沢や強いぼかしは使わない。季節の気配は草木、水の色と小さな花で描く。現実の写真には画風を適用しない。

人物は原寸およそ16×24のドットで頭と胴の比がおおむね1対1。顔、髪、上着、靴などを同じ整数座標に重ね、顔立ちと肌の色は独立して選べる。輪郭は1ドットを基本にする。動作の違いは腕・脚・道具の位置で読み取れるようにする。画面の文字はドットにせず、タップは絵より大きな領域で受ける。

音は希望した場合のみ。動きの軽減設定に従い、動作を静止姿勢でも識別できるようにする。地理に基づく地図と創作の街並みはそれぞれ明示する。
