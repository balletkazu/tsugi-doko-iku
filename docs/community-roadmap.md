# 旅のコミュニティと横断検索

世界が主役で、ユーザーが主人公。写真、旅の日記、公開ジャーナリング、栞を通じて、次の人が旅に出るきっかけを持ち帰れる場にする。

## 現在のプレビュー

ホームは有限のフィード。みんなの旅、フォロー中、写真、旅の日記、旅の栞を切り替えられる。投稿には編集部のサンプルであることを表示する。ハッシュタグは表示用で、アカウントや横断検索には接続していない。フォロー、保存、5種類の反応は IndexedDB でこの端末に保存する。日記と栞の個人データから、投稿を自動で作成することはない。

## 招待試行までの実装手順

1. **アカウントと権限**。認証付きプロフィール、アカウント削除、エクスポート、サーバー側の認可を用意する。技術候補は管理された PostgreSQL と認証、オブジェクトストレージ。採用前に料金、データ保管地域、メール配信制限、退会時の削除、復元方法を比較する。公開名と内部 ID を分ける。
2. **投稿と公開範囲**。自分だけの日記、栞、写真を作り、本人が選んだ内容から共有用の投稿を作成する。既定は `private`。プレビュー確認後に `restricted`（許可したアカウントのみ）か `public` を選ぶ。本文、添付画像、サムネイル、検索候補、通知、共有リンクのすべてに同じ公開範囲を適用する。公開範囲の縮小・投稿削除で配信と検索への露出を解除する。限定・非公開の応答を共有 CDN にキャッシュしない。
3. **フォロー、保存、コメント**。プロフィールと投稿 ID を参照し、再試行で二重登録されない保存・フォローを提供する。保存一覧は本人だけが閲覧できる。フォロー中のフィードと有限の編集特集に区切りを入れる。コメントの最初の公開前に、削除、通報、モデレーション、連投制限、通知の停止を揃える。
4. **リアクションと通知**。「いいね」「ありがとう」「行ってみたい」「参考になった」「旅してきたよ」を、ユーザー・投稿・種類ごとに重複なく保存する。投稿者に「あなたの栞を見て旅してきた人がいる」といった意味の分かる通知を送る。通知は本人が管理し、まとめて確認できる。公開の人気順位やフォロワー数で並び替えない。貢献への表彰は将来、役立った情報の更新、旅の知恵の共有などを軸に、本人が表示を選べる設計にする。
5. **横断検索**。旅先、公開投稿、写真、栞、公開プロフィール、ハッシュタグを対象にする。地名・表記ゆれ・全角半角・ひらがなとカタカナを揃え、パイロットでは Postgres の日本語向け正規化と `pg_trgm` などで検証する。「種類」「地域」「タグ」を選べるようにし、関連性と更新日を使う。公開範囲とブロックを満たした行だけを検索結果・件数・サジェストに含める。限定投稿は許可済みアカウントの閲覧経路に限る。外部インデックスは、削除と権限同期を検証してから採用する。
6. **安全管理**。ブロックは相互の閲覧・コメント・フォロー・通知に適用する。ミュートは本人の表示や通知に適用する。通報は本文と必要な情報を運営向けキューに送り、対応記録、再審査、濫用対策を用意する。個人情報、著作権、危険な場所や希少な自然の位置を通報項目に含める。権限の組み合わせや検索・画像 URL からの漏えいを招待試行前にテストする。

## 利用者の写真をホームに掲載する仕組み

写真は `Photo` に画像参照、撮影者名、表示用の撮影場所、代替テキスト、出典、ライセンス情報、公開状態、掲載許諾の版、審査状態を持つ。ホームは `Photo` の ID を参照する。Commons の場合は出典とライセンスの確認済みカタログを使い、利用者の写真には一般公開に加え、ホーム掲載への別途同意と審査を求める。撮影者・権利者の許可と必要な権利を確認し、使途、見せる場所、期間、取り下げ方法を明示する。

投稿者が公開範囲を変更、掲載許諾を撤回、写真を削除した時点でホーム参照と画像配信を解除する。利用者のメディアはサービスワーカーの固定プリキャッシュに含めない。撮影位置は既定で公開せず、EXIF の GPS データを除去する。場所の表示はユーザーが選んだ地域名を基本とする。検索用の位置情報と公開用の位置を分離する。プレビューで使う画像の詳細は [写真の出典と許諾](photo-credits.md) に記録する。

## 後続機能

- 都道府県、国立公園、世界遺産、ユネスコ世界ジオパーク、ユネスコエコパーク、日本百名山の公式一覧と識別子を揃える。地図、スタンプ帳、貢献への表彰から確認できるようにする。
- 栞の写真・表紙・紙色・装飾を増やす。印刷や共有時に、出典のある画像と交通情報の利用条件を守る。
- 日記と自己発見には、気持ち、旅人タイプの振り返り、利用者だけが閲覧できる集計を加える。
- GPS 記録は明示的な開始・停止と端末内保存から始める。公開用には自宅付近・軌跡の開始終了位置などを隠す選択肢を用意する。カメラ撮影とデジタルカメラからのファイル取り込みは、実機のファイル選択と権限管理を確認して提供する。
